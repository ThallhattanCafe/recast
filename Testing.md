# Testing and troubleshooting

```sh
python -m unittest discover -s . -p "test_*.py"
python demo.py
```

The tests use generated bytes and invented dialogue. They cover round trips, zero-run rejection, streaming limits, padding, text pointers, name and timing commands, and checked graphics rectangles. Additional cases cover sparse gender banks, native date-grid cells, reviewed corrections, legacy opening overrides and explicit wording expectations. They do not boot a game.

## Audit a local text revision

```sh
python audit_scenario.py local-data/original-scenario.bin --before local-data/before.json --after local-data/after.json --corrections local-data/corrections.json --expectations local-data/expectations.json --report local-data/audit.json
```

The two optional files are described in [File formats](File-formats.md#reviewing-a-revision). Omit `--corrections` when no existing wording changes, and omit `--expectations` when no specific word checks are needed.

The audit rejects removed translations, unreviewed changes, stale corrections and references to missing entries. It repacks the original source, reads back every text pointer and checks changed entries for preserved variables and timing. Legacy opening translations are included when checking overrides. Four-line entries and text with dynamic variables or timing commands are flagged for a closer look in-game.

A passing report does not certify the English or the character's gender. Wording expectations are assertions supplied by the reviewer. The report deliberately omits dialogue, but the source, specs and review inputs still belong in your private working files.

## Check real changes in-game

Build into a fresh folder. Cold-boot the new image, load an in-game memory-card save, and play through the changed scene. Check choices, names, line boundaries, pauses, and the transition back to normal play. Check each protagonist branch you edited.

Old emulator states can contain old text and code in RAM. Loading one into a new build does not reliably test the new disc. Modified states can help inspect branches, but record them as fixtures rather than ordinary playthroughs.

The separate translation project has used targeted PCSX ReARMed HLE checks. Those checks do not prove real-BIOS compatibility or full-year completion. The emulator harness and game states are not included here.

## Common failures

- **Source image does not match:** verify the revision and dump. Do not change the expected hash just to silence the check.
- **Text exceeds its allocation:** shorten it or investigate the layout before relocating anything.
- **Missing variable:** preserve the source name/date command and its argument.
- **Timing command order/count changed:** retain the original timing structure, then inspect the translated scene.
- **Unsafe CD decode work:** keep the eight-word copy cap and 16,000-byte sector budget. Offline decompression is not enough.
- **Compressed asset exceeds allocation:** investigate the data and compression. Enlarging a recorded allocation does not relocate the file safely.
- **Refusing to overwrite:** use another output folder.

Use normal Python, without `-O`, so assertion-based checks remain active.
