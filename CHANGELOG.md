# Changes

## 28 October 2026

The scenario repacker now handles the observed male-only bank layout without renumbering the shared banks that follow the empty gender slot. The behavior is opt-in through `allow_sparse_gender`.

Native date-table tokens preserve digit indices, label positions and numeric grid spacing. The encoder checks the source shape before using them and refuses to reuse nonnumeric rows.

The project's revision checks are available as `audit_scenario.py`. It accepts local paths instead of relying on the translation workspace. Existing translations, including legacy opening dialogue, need an exact reviewed correction before they can change. The audit also checks repacked pointers, variables, timing and reviewer-selected wording. Reports contain no dialogue.

New tests use generated bytes and invented text. The public builder still takes a separately supplied manifest; no translation specs, source assets, emulator states or game images are bundled.

These changes support the current SLPS-02120 format. Other games remain untested. The remaining combat-exam instructions and move lists have not been added to the supported translation workflow yet.
